# passe-plat-install (archived)

**English** — This repository is archived. The installer it published is no longer used
and should not be run. The app is now called **Nekoia**, and it installs nothing on your
machine: pairing adds a single line to `authorized_keys`, nothing else.

See https://nekoia.app
